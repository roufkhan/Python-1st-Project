🏧 ATM Simulation System (Python)

My first small Python project! 🎉

This is a simple ATM Simulation System built using Python. It allows users to log in using a PIN and perform basic ATM operations through a menu-driven program.

🚀 Features
🔐 PIN-based login system
💰 Check account balance
📥 Deposit money
📤 Withdraw money
⚠️ Insufficient balance warning
🚪 Exit the ATM system
❌ Invalid PIN and menu option handling
🛠️ Technologies Used
Python 3
if-else statements
while loop
match-case
User input (input())
Basic arithmetic operations
📋 Default Login Details
Detail	Value
PIN	1234
Initial Balance	50000
